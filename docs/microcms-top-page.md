# トップページのmicroCMS対応（2026-07-27）

トップページ（`app/page.tsx`）のヒーローと「余白」セクションを、microCMSの `pagehero` API から編集できるようにした。

## 使い方（管理画面）

https://oceanquest.microcms.io/apis/pagehero の **ページ識別子 = `top`** のコンテンツを編集する。

| フィールド | 反映先 | 現在の値 |
|---|---|---|
| ページ識別子 | （固定） | `top` |
| キッカー | ヒーロー上の小さい行 | `OCEAN QUEST — 海洋産業のキャリア・採用支援` |
| 見出し | ヒーローのh1（1行目＝前フリ小・2行目＝主役大） | `日本の国土は、世界61位。`<br>`深海の海水量は、世界【1位】。` |
| リード文 | ヒーロー下のリード | `海に眠っているのは資源だけじゃない。`<br>`このポテンシャルも。あなたのキャリアも。` |
| セクションキッカー | 「余白」セクションの大きい行 | `日本は、深海で【世界一】の国だ。` |
| セクション見出し | 「余白」セクションの小さい注記 | `水深5,000m以深の海水保有体積は世界1位。領海と排他的経済水域（約447万km²）は世界6位。` |

**2026-08-19更新**: メインメッセージを「国土61位・海6位」から「深海（水深5,000m以深）の海水保有体積が世界1位」に差し替え（ミネさんFB）。出典: 笹川平和財団 海洋政策研究所 Ocean Newsletter「わが国の200海里水域の体積は？」（https://www.spf.org/opri/newsletter/123_3.html）。旧来の「国土61位・海6位」（EEZ面積）はセクション見出しに残し、深さの文脈で使う。**この差し替えは`app/page.tsx`のフォールバック文言のみに反映済み。microCMS側（下記URL）の`top`コンテンツは人が手動で上表の値に更新し、「公開」ボタンを押す必要がある**（CMSに値が入っている限りコード側の変更は本番に反映されない）。

## 記法（覚えるのは2つだけ）

- **改行** → そのまま行が分かれる（h1は1行目が自動的に小さい前フリ行になる）
- **【…】** → 強調。先頭が数字なら数字だけ大きくなる
  - 例: `世界【6位】。` → 世界 **6**位。（6がオレンジで大きい）
  - 例: `日本は、【海の国】だ。` → 「海の国」にマーカー装飾

## 実装

- `components/CmsText.tsx` — 記法をJSXに変換する（`CmsHeroHeading` / `CmsLines`）
- `app/page.tsx` — `fetchMicroCmsPageHero("top")` で取得。**未設定・API不通なら `topHeroFallback` の初期文言にフォールバック**するので、CMS側を消してもトップは壊れない

## 注意

- microCMSのコンテンツAPIキーは**読み取り専用**（POSTは403）。コンテンツ追加は管理画面から行う
- 管理画面の「公開」ボタンはブラウザ自動操作（CDP）だとハングするため、**人が押す必要がある**
